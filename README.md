# notes-manager
I wrote this code myself while learning Python. It's my original work based on the concepts I've studied

## How to Run

1. Make sure Python 3 is installed.
2. Download `notes_manager.py`.
3. Open a terminal in the folder with the file and run:  
   `python notes_manager.py`

## How to Use

After running, you'll see a menu:

1. **Show notes** – displays all notes with numbers.
2. **Add note** – prompts you to enter a new note.
3. **Delete note** – shows notes and asks for a number to delete.
4. **Exit** – quits the program.
